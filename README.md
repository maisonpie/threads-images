# threads-images

Threads 게시용 사진 보관 저장소입니다. **공개 저장소**이므로 Threads에 올릴 사진만 넣으세요.

- 사진은 `images/` 폴더에 `YYYY-MM-DD-글번호-순번.jpg` 형식으로 올립니다. 예: `images/2026-11-04-4-1.jpg`
- 주소 형식: `https://raw.githubusercontent.com/maisonpie/threads-images/main/images/<파일명>`
- 이 주소를 비공개 저장소 `threads-automation` 의 `calendar.csv` `images` 열에 `|` 로 이어 씁니다.
